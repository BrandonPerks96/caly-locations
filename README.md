## Introduction
Welcome to the Calybre Travel Claim web application! This project is designed to streamline the process for consultants at Calybre to calculate travel distances and associated costs for reimbursements when visiting client destinations.

## Project Overview
The Calybre Travel Claim web application empowers consultants to efficiently manage their travel claims. Consultants can input their starting location and the destination of the client they intend to visit. Leveraging this input, the application calculates the distance between these two points and determines the associated travel cost for the trip, which they can then claim back from Calybre. Additionally, the application offers a comprehensive view of consultants' claim history, providing details of their previous trips.

## Features
- Input Trip Details: Consultants can enter their starting location and the destination of the client they plan to visit.
- Automated Distance Calculation: The application automatically calculates the distance between the starting location and the client's destination.
- Cost Estimation: Based on the calculated distance, the application determines the associated travel cost for the trip.
- Claim History: Consultants can view a history of their previous trips and associated claims.
